# AI Companion Chat App

An interactive AI-powered companion chat application built using modern web technologies. This project simulates human-like conversations using AI and provides a smooth, engaging user experience.

---

## 🚀 Features

* 💬 Real-time AI chat interface
* 🧠 Smart responses using Gemini API
* ⚡ Fast frontend powered by Vite + React
* 🔒 Secure API handling with backend (Node.js + Express)
* 🎨 Clean and responsive UI
* 📦 Component-based architecture

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Vite
* CSS / Tailwind (if used)

### Backend

* Node.js
* Express.js

### API

* Gemini API (Google AI)

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/your-repo.git
cd ai-girlfriend
```

---

### 2️⃣ Install dependencies

#### Frontend:

```
npm install
```

#### Backend:

```
cd ai-gf-backend
npm install
```

---

### 3️⃣ Environment Variables

Create a `.env` file inside **backend folder**:

```
API_KEY=your_gemini_api_key
```

⚠️ Never share your API key publicly.

---

### 4️⃣ Run the project

#### Start backend:

```
cd ai-gf-backend
node server.js
```

#### Start frontend:

```
npm run dev
```
